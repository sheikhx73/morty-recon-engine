# MORTY (C-137) - Recon Engine

MORTY is a Python-based network reconnaissance tool designed to perform 
multi-threaded TCP port scanning, service enumeration, OS inference, and 
basic vulnerability risk classification.

---

## 🚀 Features

- Multi-threaded TCP port scanning
- Service banner grabbing
- Basic OS detection logic
- Risk-based vulnerability classification (High/Medium/Low)
- Automated structured scan report generation
- Clean CLI interface

---

## 🛠 Technologies Used

- Python
- Socket Programming
- Threading
- TCP/IP Networking Concepts

---

python scanner.py
